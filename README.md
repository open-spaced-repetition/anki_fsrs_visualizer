# Anki FSRS Visualizer

Shows how intervals depend on parameters.

https://open-spaced-repetition.github.io/anki_fsrs_visualizer/

![Screenshot](docs/video1.gif?raw=true)

You can use query params to set initial state:

Select a model with `a=fsrs-7`, `fsrs-6`, `fsrs-5`, or `fsrs-4.5`.
FSRS-7 supports SS/SF stability, fractional-day intervals, and 34 parameters clamped by ts-fsrs.
